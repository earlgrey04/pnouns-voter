pNouns ⚡ DAO — 運営からの提案

Snapshot 投票はそのまま、Nouns DAO への反映だけを全自動にする

2026年8月20日 ・ アールグレイ ・ 提案する仕組みは、実際の Snapshot とテストネットの Nouns DAO を使って一気通貫の動作確認済みです。この 1 枚に、現状・新しい仕組み・実証結果・費用・進め方をまとめました。

この資料での場所の表し方
ローカル アールグレイの自宅 PC(PC が止まると止まる) クラウド インターネット上のサービス(Snapshot、Cloudflare、GitHub、Discord) オンチェーン Ethereum ブロックチェーン上(改ざん不可・誰でも検証可)

1. いまの運用と課題

自動ローカル① 検知・要約自宅 PC の常駐プログラムが Nouns の新提案を検知し、日本語要約を生成。
人クラウド② 承認アールグレイが GitHub 上で要約を確認・承認。
自動クラウド③ Snapshot に提案作成GitHub Actions が bot の署名で投票ページを作成。
メンバークラウド④ Snapshot で投票署名のみ・ガス代 0 円。
人オンチェーン⑤ Nouns へ反映(手動)アールグレイが結果を確認し、手動で Nouns DAO に投票。告知・報告も手動。
課題: 最後の⑤(締切の見張り → 結果確認 → 投票 → 報告)が毎回人の作業で、遅れ・忘れ・属人化のリスクがある。①は自宅 PC 依存。

2. 提案 — メンバーは何も変えず、⑤を仕組みに置き換える

Snapshot での投票は、実は本人のウォレットが作る「署名」で、誰でも取得・検証できます。そこで、署名を検証して集計するコントラクト(pNouns Voter)をオンチェーンに置き、次の流れに置き換えます。

メンバークラウド今までどおり Snapshot で投票画面も手順も一切変わりません。ガス代 0 円(ETH ゼロのウォレットでも可)。
自動(リレイヤー)クラウド署名を取得してチェーンへ送るCloudflare 上の自動プログラムが Snapshot から投票署名を取得し、まとめて 1 つのトランザクションでコントラクトへ送信。ガスは立て替え → コントラクトの預け金からその場で自動返金(誰が送っても損しない)。
自動(コントラクト)オンチェーン検証・集計「この署名は本当に pNouns 保有者がこの提案に投じたものか」を検証し、NFT の保有数(1 枚 = 1 票)で集計。同じ NFT の二重カウント不可。誰も(運営もクラウドも)票を偽造・改ざんできません。投票のやり直しは新しい署名が有効。
自動(コントラクト)オンチェーンNouns DAO へ投票締切後に誰でも実行でき、集計どおりに投票(理由欄に pNouns の集計を永続記録)。ガスは Nouns DAO から返金。

Discord への「📢 受付開始 → 🗳️ 集計状況 → ✅ Nouns DAO へ投票完了」の通知も全自動になります。変わらないもの: Snapshot での投票体験・要約の人による承認(②)。なくなるもの: ⑤の手動作業と自宅 PC 依存。

投票ルール

  • 重み = 保有 pNouns 枚数(オンチェーンで検証)。トレジャリー分(13 枚)は除外。定足数なし。
  • 同数なら投票者数が多い方、それも同数なら棄権 (暫定 — ご意見で変更可能)。誰も投票しなければ Nouns には投票しない。
  • コントラクトは書き換え不可。NFT や資産は預けない(預けるのはガス返金用の ETH のみ)。やめる時はマルチシグが委任先を戻すだけ(1 トランザクション。以後の提案から有効)。

3. 実証済み — 本物の Snapshot ＋ テストネットの Nouns DAO で一気通貫

テスト環境: 投票は本物の Snapshot(テスト用スペース earl-grey.eth)。Nouns DAO 側は Ethereum 公式テストネット(Sepolia)にある Nouns 開発チーム公開の本番と同一プログラムのテスト版 DAO。pNouns NFT も本物と同じプログラムの複製を使用。

  • 無人の通し: Snapshot の 3 票(賛成 3 枚/棄権 3 枚の同数 → 投票者数 2:1 で賛成)を自動集計し、Nouns DAO に賛成 2 票を記録。人手ゼロ・Discord 通知まで自動。
  • 実際の UI からの投票: アールグレイが snapshot.box の画面から通常どおり投票 → その 3 枚分が集計に反映され、Nouns DAO へ自動投票(Nouns DAO 側の記録。理由欄に pNouns の集計つき)。
  • 本物の投票署名でも検証: 過去の pNouns の Snapshot 投票(Prop 989 の実署名 3 票)を取得し、オンチェーン検証・集計が成立することを確認。投票パワー(1/5/9)も NFT 保有数と一致。
  • 第三者監査: 基盤部分は AI 監査(Codex)6 回で重大指摘ゼロ・全 32 件対応済み。今回の Snapshot 検証部分も追加監査を実施予定。

4. 費用

場面ガス代誰が払う → どう返る
メンバーの投票(署名)0 円署名はブロックチェーンに書き込まないため発生しない
署名をチェーンへ送る提案 1 本 約 25 円(現在の相場)送った人が立て替え → コントラクトの預け金から同一トランザクション内で自動返金
Nouns DAO への投票実行約 25 円実行した人が払い → Nouns DAO から自動返金(公式機能)
預け金(返金の原資)—トレジャリーから 0.05 ETH(≒1.5 万円)を想定。残高・支出はオンチェーンで透明、余りは回収可、減れば Discord に自動警告

年間の実費はガス相場次第で約 600 円〜1.2 万円(投票者 4 名・全提案投票の場合)。運用基盤(Cloudflare)は無料枠で開始します。

5. 進め方(メンバー合意なしに本番投票は始まりません)

  1. メインネットに「見学モード」で設置 — Nouns へは投票せず、実際の提案で集計だけ行い、いまの手動運用と結果を突き合わせる(数提案)。
  2. 結果の一致を確認 → メンバー合意。
  3. マルチシグが Nouns 投票権の委任先をコントラクトへ変更(1 トランザクション・いつでも戻せる)+ トレジャリーから預け金 → 本番運用開始。以後、反映は無人。
