pNouns ⚡ DAO ・ 資料 1/3 — 現行の運用

いまの「Snapshot 投票 → Nouns DAO 反映」のしくみ（ヒト＋自動化）

2026年8月20日 ・ アールグレイ ・ Nouns DAO の提案を pNouns の Snapshot に映して投票し、結果を Nouns DAO に反映するまでの現行フロー。自動とヒトの分担を整理しました。

1. 全体の流れ

自動(ローカルPC)① 提案の検知・要約この PC の常駐ジョブ(15分ごと)が Nouns DAO の新提案(投票開始)を検知し、AI が日本語要約を生成。GitHub にドラフト(Pull Request)を作成。
ヒト② 承認アールグレイが PR の要約文を確認・修正してマージ。
自動(GitHub Actions)③ Snapshot に提案作成マージを合図に GitHub Actions が bot ウォレット(pNouns 1 枚保有)の署名で pnounsdao.eth に提案を投稿。投票期間 48 時間。
ヒト(半自動)④ 告知下書きは自動生成 → アールグレイの承認後、本人アカウントで Discord #🔥｜p⚡雑談 に「Prop N をあげました」を投稿。
メンバー→ヒト⑤ 投票と反映メンバーは Snapshot で署名投票(ガス0)。締切後、アールグレイが結果を確認し、委任先ウォレットから手動で Nouns DAO に castVote。結果報告も手動。

2. 登場する構成要素

要素役割種別
pnouns-mirror(このPCの常駐ジョブ)Nouns 提案の検知、日本語要約の生成、GitHub へのドラフト作成自動
GitHub リポジトリ + Actions要約の承認フロー(PR)と、Snapshot への提案投稿(bot ウォレットの鍵は Actions の secret)自動(承認はヒト)
Snapshot(pnounsdao.eth)メンバーの投票。重み = pNouns 保有枚数、定足数 210、期間 48h。投票は署名のみでガス不要外部サービス
告知ジョブ + DiscordSnapshot 投稿を検知して告知文を下書き → 承認後に投稿半自動
Nouns NFT 保有マルチシグ → 委任先ウォレットNouns DAO への投票権(2票)。投票操作は毎回ヒトヒト

3. 現行の課題

  • 最後の反映が手動: Snapshot 締切の監視 → 結果確認 → Nouns DAO への投票 → 結果報告、が毎回ヒト。遅れ・忘れのリスクが残る。
  • 鍵の運用: 委任先ウォレットの秘密鍵で毎回手動送信している。
  • 属人化: ②④⑤がアールグレイに依存。不在時は止まる。
  • Snapshot の結果とオンチェーンの投票の対応が、外からは追いにくい。
